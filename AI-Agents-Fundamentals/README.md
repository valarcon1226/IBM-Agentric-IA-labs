# AI Agents Fundamentals

This directory contains foundational projects exploring the core mechanics of Agentic AI, Tool Calling, and LangChain Expression Language (LCEL).

## Projects Included
- **AI Math Assistant (Tool Calling)**: An agent equipped with specific mathematical tools to overcome the innate arithmetic limitations of standard LLMs.
- **LLM-Powered Data Science (LCEL)**: Data analysis workflows orchestrated using the declarative LangChain Expression Language.

## Tech Stack
- LangChain (LCEL)
- OpenAI API
- Python / Jupyter Notebooks
