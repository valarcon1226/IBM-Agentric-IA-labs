# Machine Learning Evaluation Protocol: Document Classifier (Paperless-ngx)

This protocol formalizes the pre-registered evaluation plan for the Paperless-ngx automatic document classifier ("Auto" matching algorithm) prior to test execution.

---

## 1. Objective and Classifier Overview

Paperless-ngx includes an automated document-type classifier based on scikit-learn (`CountVectorizer` with n-grams `(1, 2)` and linear classification). When a document type has `matching_algorithm = MATCH_AUTO` (value 6), the model is trained on previously categorized documents and predicts the document type for newly ingested documents.

The goal is to measure classification precision, recall, and F1 across all supported back-office document classes under strict train/test separation.

---

## 2. Dataset and Pre-Registered Split

- **Corpus Size:** 600 synthetic text-layer PDFs generated by `corpus/generate.py`.
- **Classes (5 types):** `invoice`, `purchase_order`, `bank_statement`, `utility_bill`, `letter`.
- **Correspondents:** 12 distinct organizational entities.
- **Data Split:**
  - **Training Set:** 500 documents, stratified by document type (100 documents per type). Ingested with pre-assigned document type labels.
  - **Held-Out Test Set:** 100 documents, stratified by document type (20 documents per type). Ingested without labels to assess model inference.
- **Seeds:** Evaluated over 3 distinct random seeds (Seed 42, Seed 101, Seed 202) to verify statistical stability.

---

## 3. Evaluation Metrics and Pre-Registered Thresholds

Evaluation metrics are computed directly in pure Python (no sklearn dependency in the evaluation runner):
- **Per-Class Metrics:**
  - Precision: $P_c = \frac{TP_c}{TP_c + FP_c}$
  - Recall: $R_c = \frac{TP_c}{TP_c + FN_c}$
  - F1-Score: $F1_c = 2 \times \frac{P_c \times R_c}{P_c + R_c}$
- **Macro-F1:**
  $$\text{Macro-F1} = \frac{1}{|C|} \sum_{c \in C} F1_c$$
- **Confusion Matrix:** Full $5 \times 5$ contingency table of actual vs. predicted classes.

### Acceptance Thresholds (Gates):
1. **Macro-F1:** $\ge 0.90$ (mean across 3 runs).
2. **Minimum Type Recall:** $\ge 0.80$ for every individual document type (no class blind spots).

---

## 4. Caveats and Limitations

> [!NOTE]
> **Synthetic Corpus Upper Bound:**
> The documents in this benchmark are generated from structured synthetic templates with realistic fields and vocabulary. Synthetic documents exhibit lower typographical noise, fewer scanning artifacts, and cleaner token distributions than real-world physical mail, receipts, or legacy faxes. Therefore, the metrics reported here represent an **empirical upper bound** of classifier performance under clean text-layer conditions.
