# AI Meeting Assistant

An intelligent assistant designed to transcribe, analyze, and generate actionable insights from meeting audio recordings.

## Features
- **Speech-to-Text Transcription**: Automatically transcribe recorded meetings.
- **Key Term Extraction**: Identifies and standardizes specific product-related terminology.
- **Action Item Generation**: Generates automated meeting minutes and assigns tasks based on the transcript.

## Tech Stack
- IBM watsonx.ai
- Whisper (Speech-to-Text)
- Python & Gradio
