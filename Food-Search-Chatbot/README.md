# Food Search Chatbot

A professional-grade semantic search chatbot that helps users discover food items and recipes based on natural language queries, going beyond simple keyword matching. This repository contains the core logic for calculating vector distances and cosine similarities for embedded text.

## Features
- **Semantic Search Core**: Robust vector distance and similarity calculation tools.
- **Vector Embeddings**: Utilities that leverage state-of-the-art embedding models to convert text descriptions into high-dimensional vectors.
- **Interactive UI Support**: Ready for integration with Gradio for a seamless user chat experience.

## Tech Stack
- `Sentence Transformers` / `PyTorch` (Embeddings & Machine Learning)
- `NumPy` & `SciPy` (Scientific Computing)
- `ChromaDB` (Vector Database Integration)
- `Gradio` (Interactive UI)
