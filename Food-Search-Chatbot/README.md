# Food Search Chatbot

A semantic search chatbot that helps users discover food items and recipes based on natural language queries, going beyond simple keyword matching.

## Features
- **Semantic Search**: Understands the meaning behind user queries to find related foods, even if the exact words don't match.
- **Vector Embeddings**: Converts food descriptions into high-dimensional vectors for similarity comparison.
- **Interactive UI**: Built with Gradio for a seamless user chat experience.

## Tech Stack
- ChromaDB (Vector Database)
- OpenAI / LLM Embeddings
- Python & Gradio
