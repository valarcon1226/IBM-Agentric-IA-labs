# YouTube RAG Analyzer

An AI agent capable of summarizing and answering complex queries based on YouTube video transcripts.

## Features
- **Video Transcript Analysis**: Connects to video transcripts and indexes their content.
- **Context-Aware Retrieval (RAG)**: Uses Retrieval-Augmented Generation to ensure all answers are strictly grounded in the video's content.
- **Policy Enforcement**: Integrates with company policies to validate the generated responses before presenting them to the user.

## Tech Stack
- LangChain
- Vector Databases
- Python
