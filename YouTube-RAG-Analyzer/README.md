# YouTube RAG Analyzer

An AI agent application capable of summarizing and answering complex queries based on YouTube video transcripts. This project leverages LLMs to provide intelligent search, summarization, and data extraction from videos.

## Features
- **Video Transcript Analysis**: Extracts transcripts and metadata directly from YouTube.
- **Agentic Chatbot**: Interact directly with an AI assistant to query video content, find videos, and get summaries.
- **Batch Processing**: Process multiple YouTube URLs simultaneously to quickly summarize and extract metadata from multiple sources.

## Tech Stack
- Python
- LangChain
- Gradio
- yt-dlp & youtube-transcript-api

## Setup
Install dependencies:
```bash
pip install -r requirements.txt
```

Run the application:
```bash
python main.py
```
