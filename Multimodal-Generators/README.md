# Multimodal AI Generators

A collection of multimodal AI applications focusing on image generation and personalized audio storytelling.

## Projects Included
1. **AI Storyteller**: Uses Mixtral (LLM) to generate creative stories and gTTS (Google Text-to-Speech) to narrate them out loud.
2. **DALL-E Image Generator**: A robust implementation of text-to-image generation using OpenAI's DALL-E models to create visually stunning artwork based on detailed prompts.

## Tech Stack
- Mixtral
- OpenAI DALL-E
- Google Text-to-Speech (gTTS)
- Python / Jupyter Notebooks
