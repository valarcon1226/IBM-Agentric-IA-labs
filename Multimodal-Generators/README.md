# Multimodal AI Generators

A professional python project showcasing a collection of multimodal AI applications, focusing on text generation, image generation, and personalized audio storytelling.

## Features Included
1. **AI Storyteller**: Uses a Large Language Model to generate creative, educational stories and `gTTS` (Google Text-to-Speech) to narrate them out loud.
2. **AI Image Generator**: A robust implementation of text-to-image generation using OpenAI's DALL-E models to create visually stunning artwork based on detailed prompts.

## Tech Stack
- Large Language Models (LLaMA 3)
- OpenAI DALL-E 3
- Google Text-to-Speech (gTTS)
- Python

## Getting Started

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Make sure you have your API credentials properly configured as environment variables (e.g., `OPENAI_API_KEY`).

3. Run the application:
   ```bash
   python main.py
   ```
